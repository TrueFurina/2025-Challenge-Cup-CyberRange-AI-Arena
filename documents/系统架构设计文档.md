# 系统架构设计文档

## 1. 引言

### 1.1 目的
本文档旨在详细描述“AI Agent驱动的动态攻防推演靶场平台”的系统架构设计，包括总体架构、模块划分、模块间接口、关键技术选型以及部署架构。本设计旨在满足平台在动态场景生成、智能攻击模拟、自适应防御决策和演练评估自动化方面的功能需求，并兼顾性能、可靠性、安全性、可扩展性和用户体验等非功能性需求。

### 1.2 范围
本系统架构设计涵盖平台的所有核心组件，从前端用户界面到后端服务、AI Agent模块、数据库以及外部接口。

### 1.3 术语与缩写
- **API**: 应用程序编程接口（Application Programming Interface）。
- **DB**: 数据库（Database）。
- **MQ**: 消息队列（Message Queue）。
- **RESTful API**: 一种设计风格，用于网络应用程序的API设计。
- **WebSocket**: 一种在单个TCP连接上进行全双工通信的协议。

## 2. 总体架构

平台采用分层解耦的微服务架构，以提高系统的可扩展性、可维护性和可靠性。整体架构分为以下几层：

- **用户界面层 (User Interface Layer)**: 提供直观、友好的Web界面，供演练组织者、评估者和人工参与者进行操作和查看。
- **应用服务层 (Application Service Layer)**: 核心业务逻辑层，提供各项功能服务，并通过API与前端交互，与AI Agent模块和数据层进行通信。
- **AI Agent层 (AI Agent Layer)**: 包含攻击Agent和防御Agent，负责智能决策和执行攻防行为。
- **靶场环境层 (Cyber Range Environment Layer)**: 模拟真实的IT基础设施和网络环境，是攻防演练的实际发生地。
- **数据层 (Data Layer)**: 存储平台运行所需的所有数据，包括配置数据、演练数据、日志数据、评估数据等。
- **外部接口层 (External Interface Layer)**: 与外部系统进行交互，如威胁情报平台、漏洞库等。

## 3. 模块划分与功能

### 3.1 用户界面层
- **管理控制台**: 供演练组织者进行场景配置、演练启动/停止、用户管理、报告查看等操作。
- **态势感知大屏**: 实时可视化展示攻防态势、关键指标、攻击路径、防御响应等。
- **人工操作界面**: 供人工攻击者和防御者进行手动操作和查看实时反馈。

### 3.2 应用服务层
- **场景管理服务**: 负责场景的创建、编辑、导入、导出、模板管理和动态参数调整。
- **演练管理服务**: 负责演练的生命周期管理（启动、暂停、恢复、停止）、参与者管理、权限控制。
- **攻击协调服务**: 接收攻击Agent的请求，协调攻击行为在靶场环境中的执行，并收集攻击反馈。
- **防御协调服务**: 接收防御Agent的请求，协调防御行为在靶场环境中的执行，并收集防御反馈。
- **数据采集服务**: 实时从靶场环境、Agent行为中采集各类数据（日志、流量、事件等）。
- **评估分析服务**: 对采集到的数据进行处理、分析，构建量化模型，生成评估报告和技能画像。
- **通知与告警服务**: 负责系统内部和外部的通知与告警发送。

### 3.3 AI Agent层
- **攻击AI Agent模块**: 
    - **感知模块**: 收集靶场环境信息、防御部署、漏洞信息等。
    - **决策规划模块**: 基于强化学习、规划算法等，自主规划攻击路径和策略。
    - **执行模块**: 调用攻击工具或模拟攻击行为。
    - **学习优化模块**: 根据攻击结果和防御响应，调整策略。
- **防御AI Agent模块**: 
    - **感知模块**: 实时监控网络流量、系统日志、安全设备告警等。
    - **决策规划模块**: 基于机器学习、专家系统等，自主决策防御策略（漏洞修复、威胁阻断、攻击溯源）。
    - **执行模块**: 调用安全工具或模拟防御行为。
    - **学习优化模块**: 根据防御效果，调整策略。

### 3.4 靶场环境层
- **虚拟化/容器平台**: 提供虚拟机或容器的创建、管理、销毁，用于构建隔离的靶场实例。
- **网络仿真模块**: 基于SDN技术，模拟复杂的网络拓扑、带宽、延迟、丢包等网络特性。
- **系统/应用仿真模块**: 部署各类操作系统、应用服务（Web服务器、数据库、邮件服务器等），模拟真实业务系统。
- **流量生成模块**: 模拟正常业务流量和背景流量，增加场景真实性。
- **安全设备仿真模块**: 模拟防火墙、IDS/IPS、WAF等安全设备的功能。

### 3.5 数据层
- **关系型数据库**: 存储结构化数据，如用户管理、场景配置、演练元数据、评估报告摘要等。
- **时序数据库**: 存储高频、大量的时序数据，如网络流量、系统性能指标、日志事件等。
- **文档数据库/图数据库**: 存储非结构化或半结构化数据，如威胁情报、漏洞知识库、攻击链图谱、技能画像详细信息等。
- **文件存储**: 存储大文件，如录屏、报告附件、Agent模型等。

### 3.6 外部接口层
- **威胁情报接口**: 对接外部威胁情报平台，获取最新的威胁信息。
- **漏洞库接口**: 对接外部漏洞数据库，获取最新的漏洞信息。
- **第三方工具接口**: 预留与第三方安全工具（如渗透测试工具、安全扫描器）集成的接口。

## 4. 模块间接口与通信

- **用户界面层与应用服务层**: 主要通过RESTful API进行同步通信，部分实时数据（如态势感知数据）可能通过WebSocket进行推送。
- **应用服务层与AI Agent层**: 通过消息队列（MQ）进行异步通信，实现解耦和削峰填谷。例如，攻击协调服务向MQ发送攻击任务，攻击Agent从MQ消费任务并执行，执行结果再通过MQ反馈给协调服务。
- **应用服务层与靶场环境层**: 通过API或SDK与虚拟化/容器平台、网络仿真模块进行交互，进行环境的创建、配置、监控和销毁。
- **数据采集服务**: 实时从靶场环境层和AI Agent层收集数据，写入数据层。
- **评估分析服务**: 从数据层读取数据进行分析，并将结果写入数据层。
- **各服务间**: 内部服务间通信主要通过RESTful API或gRPC。

## 5. 关键技术选型（初步）

- **后端开发语言**: Python (生态丰富，AI/ML库支持好) / Go (高性能，并发处理能力强)
- **Web框架**: Flask / FastAPI (Python) 或 Gin / Echo (Go)
- **数据库**: 
    - 关系型: PostgreSQL / MySQL
    - 时序型: InfluxDB / Prometheus
    - 文档型: MongoDB
    - 图数据库: Neo4j (用于知识图谱和攻击链分析)
- **消息队列**: Kafka / RabbitMQ
- **虚拟化/容器**: Docker / Kubernetes (容器编排) / KVM (虚拟机)
- **网络仿真**: Open vSwitch / Mininet (SDN)
- **AI/ML框架**: TensorFlow / PyTorch (用于Agent模型训练和推理)
- **前端框架**: React / Vue.js
- **可视化库**: ECharts / D3.js

## 6. 部署架构

平台将支持云原生部署，利用Kubernetes进行容器编排和管理，实现服务的弹性伸缩、高可用和自动化运维。数据库、消息队列等组件可部署为独立服务或使用云服务提供商的托管服务。
