# AI Agent驱动的动态攻防推演靶场平台 - 部署手册

## 1. 概述

本部署手册为"AI Agent驱动的动态攻防推演靶场平台"提供完整的部署指导，包括环境准备、系统安装、配置调优和运维管理等内容。平台采用前后端分离架构，支持容器化部署和云原生部署模式，确保系统的高可用性和可扩展性。

### 1.1 系统架构概述

平台采用分层架构设计，包括：
- **用户界面层**：基于React的现代化Web界面
- **应用服务层**：基于Flask的RESTful API服务
- **AI Agent层**：智能攻防决策引擎
- **靶场环境层**：虚拟化网络环境和容器编排
- **数据层**：多类型数据库支持
- **外部接口层**：威胁情报和第三方工具集成

### 1.2 部署模式

平台支持以下部署模式：
1. **单机部署**：适用于开发测试和小规模演练
2. **集群部署**：适用于生产环境和大规模演练
3. **云原生部署**：支持Kubernetes容器编排
4. **混合云部署**：支持公有云和私有云混合部署

## 2. 环境要求

### 2.1 硬件要求

#### 最小配置（单机部署）
- **CPU**：8核心 Intel/AMD x86_64处理器
- **内存**：16GB RAM
- **存储**：500GB SSD硬盘
- **网络**：千兆以太网接口

#### 推荐配置（生产环境）
- **CPU**：16核心 Intel/AMD x86_64处理器
- **内存**：64GB RAM
- **存储**：2TB NVMe SSD硬盘
- **网络**：万兆以太网接口
- **GPU**：NVIDIA Tesla V100或同等性能GPU（可选，用于AI加速）

#### 集群配置（大规模部署）
- **管理节点**：3台，每台16核心、32GB内存、1TB SSD
- **计算节点**：5-10台，每台32核心、128GB内存、2TB SSD
- **存储节点**：3台，每台8核心、16GB内存、10TB HDD

### 2.2 软件要求

#### 操作系统
- **Linux**：Ubuntu 20.04 LTS / CentOS 8 / RHEL 8
- **容器运行时**：Docker 20.10+ / containerd 1.4+
- **容器编排**：Kubernetes 1.20+ / Docker Swarm

#### 基础软件
- **Python**：3.8+
- **Node.js**：16.0+
- **数据库**：PostgreSQL 13+ / MySQL 8.0+ / MongoDB 4.4+
- **消息队列**：Redis 6.0+ / RabbitMQ 3.8+
- **Web服务器**：Nginx 1.18+ / Apache 2.4+

### 2.3 网络要求

- **带宽**：至少100Mbps上下行带宽
- **端口**：开放80、443、5000、5173、6379、5432等端口
- **防火墙**：配置适当的防火墙规则
- **DNS**：配置域名解析（可选）


### 4.2 配置文件准备

#### 4.2.1 Docker Compose配置

创建`docker-compose.yml`文件：

```yaml
version: '3.8'

services:
  # 数据库服务
  postgres:
    image: postgres:13
    environment:
      POSTGRES_DB: cyber_range
      POSTGRES_USER: cyber_user
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./init.sql:/docker-entrypoint-initdb.d/init.sql
    ports:
      - "5432:5432"
    restart: unless-stopped

  # Redis缓存
  redis:
    image: redis:6-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    restart: unless-stopped

  # 后端API服务
  backend:
    image: cyber-range/backend:latest
    environment:
      - DATABASE_URL=postgresql://cyber_user:${DB_PASSWORD}@postgres:5432/cyber_range
      - REDIS_URL=redis://redis:6379/0
      - SECRET_KEY=${SECRET_KEY}
      - OPENAI_API_KEY=${OPENAI_API_KEY}
    ports:
      - "5000:5000"
    depends_on:
      - postgres
      - redis
    volumes:
      - ./logs:/app/logs
      - ./uploads:/app/uploads
    restart: unless-stopped

  # 前端Web服务
  frontend:
    image: cyber-range/frontend:latest
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./ssl:/etc/nginx/ssl
    depends_on:
      - backend
    restart: unless-stopped

  # AI Agent服务
  ai-agent:
    image: cyber-range/ai-agent:latest
    environment:
      - BACKEND_URL=http://backend:5000
      - REDIS_URL=redis://redis:6379/1
      - OPENAI_API_KEY=${OPENAI_API_KEY}
    depends_on:
      - backend
      - redis
    volumes:
      - ./agent_logs:/app/logs
    restart: unless-stopped

  # 靶场环境管理
  range-manager:
    image: cyber-range/range-manager:latest
    privileged: true
    environment:
      - BACKEND_URL=http://backend:5000
      - DOCKER_HOST=unix:///var/run/docker.sock
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - ./range_data:/app/data
    depends_on:
      - backend
    restart: unless-stopped

  # 监控服务
  prometheus:
    image: prom/prometheus:latest
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
      - prometheus_data:/prometheus
    restart: unless-stopped

  # 日志收集
  elasticsearch:
    image: docker.elastic.co/elasticsearch/elasticsearch:7.15.0
    environment:
      - discovery.type=single-node
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
    ports:
      - "9200:9200"
    volumes:
      - elasticsearch_data:/usr/share/elasticsearch/data
    restart: unless-stopped

volumes:
  postgres_data:
  redis_data:
  prometheus_data:
  elasticsearch_data:
```

#### 4.2.3 Nginx配置

创建`nginx.conf`文件：

```nginx
events {
    worker_connections 1024;
}

http {
    upstream backend {
        server backend:5000;
    }

    server {
        listen 80;
        server_name _;
        return 301 https://$server_name$request_uri;
    }

    server {
        listen 443 ssl http2;
        server_name _;

        ssl_certificate /etc/nginx/ssl/cert.pem;
        ssl_certificate_key /etc/nginx/ssl/key.pem;

        location / {
            root /usr/share/nginx/html;
            try_files $uri $uri/ /index.html;
        }

        location /api/ {
            proxy_pass http://backend;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }

        location /ws/ {
            proxy_pass http://backend;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header Host $host;
        }
    }
}
```

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: postgres
  namespace: cyber-range
spec:
  replicas: 1
  selector:
    matchLabels:
      app: postgres
  template:
    metadata:
      labels:
        app: postgres
    spec:
      containers:
      - name: postgres
        image: postgres:13
        env:
        - name: POSTGRES_DB
          value: cyber_range
        - name: POSTGRES_USER
          value: cyber_user
        - name: POSTGRES_PASSWORD
          valueFrom:
            secretKeyRef:
              name: cyber-range-secrets
              key: db-password
        ports:
        - containerPort: 5432
        volumeMounts:
        - name: postgres-storage
          mountPath: /var/lib/postgresql/data
      volumes:
      - name: postgres-storage
        persistentVolumeClaim:
          claimName: postgres-pvc
---
apiVersion: v1
kind: Service
metadata:
  name: postgres
  namespace: cyber-range
spec:
  selector:
    app: postgres
  ports:
  - port: 5432
    targetPort: 5432
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: postgres-pvc
  namespace: cyber-range
spec:
  accessModes:
  - ReadWriteOnce
  resources:
    requests:
      storage: 10Gi
```

### AI 接口（前缀 /api/ai）

- `POST /api/ai/session`：创建对抗会话，body 可含 `params: {target_count, vuln_density, defense_strength}`
- `POST /api/ai/session/<id>/round`：执行一轮；`/run`：一键全部
- `GET /api/ai/session/<id>`：对抗状态；`/evaluate`：演练评估
- `POST /api/ai/scenario/generate`：动态场景生成
- 前端：`/ai-arena`（对抗大屏）、`/ai-agent-monitor`（决策监控 + 评估）

### 安全配置（部署必读）

1. **关闭 debug**：生产环境 `python app.py` 已默认 `debug=False`；建议改用 gunicorn
2. **token 鉴权**：登录返回 token，敏感接口需 `Authorization: Bearer <token>`；token 为内存存储，多进程部署需换 JWT + 持久化
3. **默认账户**：admin / admin123（请部署后立即修改默认密码）
4. **CORS**：已收紧为本地白名单，跨域调用需在 `app.py` 中显式添加来源
5. **数据初始化**：`python seed.py`（幂等，含 12 攻击 / 12 防御 / 12 漏洞 / 8 工具）
