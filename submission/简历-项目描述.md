## 一、项目经历（简历主 bullet，可直接使用）

### 项目：AI Agent 驱动的动态攻防推演靶场平台（安恒"挑战杯"揭榜挂帅赛题作品）

**担任角色**：核心开发 / 产品设计

**项目简介**：基于 Flask + SQLite + AI Agent 的攻防推演平台，实现动态场景生成、智能攻击模拟、自适应防御决策、演练评估自动化四大功能，作为安恒第十九届"挑战杯"揭榜挂帅（SH24）赛题作品提交。

**核心成果（3-4 条 bullet）**：

1. **AI Agent 攻防对抗**：自研攻击/防御双 Agent（LLM 决策 + 规则兜底），实现多轮回合制攻防对抗，攻击 Agent 可基于 12 条漏洞库自主规划多步攻击链（实测规划"SQL 注入→SSH 弱口令→WebShell"完整链路），前端大屏实时可视化决策流
2. **产品化交付**：独立完成 7 篇技术文档（需求/架构/开发/部署/测试/用户/白皮书）+ 产品 PRD + 31 个功能页面 + Prometheus/Grafana/Loki 监控栈 + Docker 一键部署，覆盖完整产品生命周期
3. **安全工程实践**：完成全站安全审计，发现并修复 11 项安全漏洞（角色注入/未授权越权/CORS 配置缺陷/调试模式 RCE 面），引入 token 鉴权体系，修复后动态验证 14/14 通过
4. **技术栈**：Python / Flask / SQLite / Jinja2 / JavaScript / Docker / Prometheus + Grafana / LLM API（DeepSeek）

## 三、面试话术（对应靶场产品实习高频题）

### Q：你理解的网络安全靶场是什么，有哪些客户？
> 网络安全靶场是提供拟真攻防环境的实训/演练平台，客户主要是高校网络空间安全专业、政企安全部门、公安比武组织。我们项目用 AI Agent 替代人工攻防对手，解决传统靶场场景静态、路径单一、评估主观的问题。

### Q：如果高校老师需要 AI 智能体攻防实训场景，你怎么做需求拆解？
> 拆成四层：① 场景层——按业务模型生成拓扑 + 按难度植入漏洞；② Agent 层——攻击 Agent 规划攻击链、防御 Agent 分级响应；③ 对抗层——回合制推进、状态可回放；④ 评估层——攻击成功率/响应时效/威胁分布量化输出。这正好对应我们平台的四大功能。

### Q：产品新版本上线，研发和销售意见冲突怎么处理？
> 先拉对齐：明确冲突点是"功能完整度"还是"交付时间"。如果销售要的演示效果不影响核心架构，可排到迭代二；如果是硬需求（如 AI 对抗必须能跑通），则压缩演示范围保核心。本质是优先级管理 + 用数据说话（我们对抗实测通过率可作依据）。

### Q：可以接受长达半年的全职实习吗？
> 可以。我目前处于备赛/考研窗口期，可全职投入 4-6 个月，且已完成安恒赛题作品，上手靶场业务零成本。
