## 一、产品概述

**AI Agent 驱动的动态攻防推演靶场平台**是一款面向网络安全人才培养与实战演练的智能化平台。平台用 AI Agent 替代传统人工攻防对手，实现**动态场景生成、智能攻击模拟、自适应防御决策、演练评估自动化**四大核心能力，解决传统靶场"场景静态化、攻击路径单一、评估主观化"的三大痛点。

## 二、为什么需要 AI Agent 靶场

### 2.1 传统靶场的三大局限

| 局限 | 传统方案 | 后果 |
|------|---------|------|
| 场景静态化 | 场景固定，重复演练 | 学员背题，失去实战价值 |
| 攻击路径单一 | 固定脚本攻击 | 无法应对真实 APT 复杂度 |
| 评估主观化 | 人工打分 | 不公平、不可量化、难复盘 |

### 2.2 AI Agent 方案的三大价值

1. **拟真度**：攻击 Agent 基于真实漏洞库（CVE）自主规划多步攻击链，防御 Agent 分级响应——模拟真实攻防对抗
2. **成本**：AI 替代人工红蓝队，支持常态化、大规模演练
3. **量化**：对抗过程全记录、评估指标全量化，可复盘、可追溯

## 三、核心功能

### 3.1 动态场景生成
- 基于业务模型自动构建网络拓扑（企业/政务/教育多行业模板）
- 按难度植入已知漏洞（12 条 CVE，含严重度分级）
- 环境参数动态调整（目标数量/漏洞密度/防御强度）

### 3.2 智能攻击模拟
- 12 种攻击技术库（SQLi/XSS/命令注入/爆破/WebShell/SSRF/CSRF 等）
- AI 攻击 Agent 自主规划攻击路径（LLM 决策 + 规则兜底）
- 实测可规划"SQL 注入→SSH 弱口令→WebShell 持久控制"完整攻击链

### 3.3 自适应防御决策
- 12 种防御策略库（WAF/IDS/隔离/补丁/账号锁定等）
- AI 防御 Agent 按威胁等级（低/中/高/严重）分级响应
- 攻防回合制对抗（最多 5 轮），决策流实时可视化

### 3.4 演练评估自动化
- 多维度指标：攻击成功率、防御响应时效、威胁分布
- 对抗结束自动生成量化评估报告
- 过程全记录，支持复盘与审计

## 四、技术架构

```
用户界面层    React/HTML 大屏 + 31 个功能页面
应用服务层    Flask RESTful API（token 鉴权）
AI Agent 层   攻击 Agent / 防御 Agent / 对抗编排器（LLM 决策 + 规则兜底）
数据层        SQLite（用户/攻击/防御/工具/漏洞/角色）+ 对抗会话
监控层        Prometheus + Grafana + Loki 全套监控
部署层        Docker Compose + nginx + CI/CD
```

## 五、应用场景

| 公安比武选拔 | 竞赛组织方 | 公平量化评估、防作弊 |

## 六、安全与合规

- 全 API token 鉴权 + 角色权限隔离（已通过安全审计，修复 11 项漏洞）
- CORS 白名单，防跨域攻击
- 演练环境隔离，不影响生产网络
- 符合教育/政务数据安全要求

## 七、部署与运维

- **一键部署**：`docker-compose up -d` 或 `python app.py`（零依赖 Mock 模式）
- **监控**：Prometheus 指标 + Grafana 可视化大屏 + Loki 日志聚合
- **数据**：SQLite 轻量存储，支持迁移扩展
