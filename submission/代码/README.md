# 网络安全靶场管理系统

一个基于Flask的现代化网络安全实训平台，提供完整的靶场管理、用户管理、竞赛中心和实验环境功能。

## 🚀 项目特性

### 核心功能
- **双角色系统**：管理员和学员分离的权限管理
- **实训场景管理**：支持多种网络安全实训场景配置
- **竞赛中心**：集成CTF、AWD等多种竞赛模式
- **实验环境**：虚拟机、容器化靶机管理
- **设备管理**：网络设备、安全设备统一管理
- **知识库**：攻击库、防御库、工具库、漏洞库

### 技术特色
- **现代化UI**：响应式设计，支持移动端访问
- **轻量级部署**：基于Flask，快速启动
- **数据持久化**：SQLite数据库，无需额外配置
- **模块化设计**：清晰的代码结构，易于扩展

## 📋 系统要求

### 最低配置
- **操作系统**：Windows 10+ / Linux / macOS
- **Python版本**：Python 3.9+
- **内存**：2GB RAM

- **内存**：4GB+ RAM

- **CPU**：双核心+

## 🔧 配置说明

### 数据库配置
系统默认使用SQLite数据库，数据文件为 `app.db`，首次启动会自动创建。

### 自定义配置
如需修改配置，可以编辑 `app.py` 文件中的相关设置：
```python
# 数据库配置
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///app.db'

# 调试模式（生产环境请设置为False）
app.run(debug=True)
```

## 🔍 故障排除

### 常见问题

#### 1. 端口占用
如果5000端口被占用，可以修改 `app.py` 文件中的端口：
```python
if __name__ == '__main__':
    app.run(debug=True, port=8080)  # 改为其他端口
```

#### 2. 依赖安装失败
```bash
# 升级pip
pip install --upgrade pip

# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

#### 3. 数据库初始化失败
```bash
# 删除现有数据库文件重新初始化
rm app.db  # Linux/macOS
del app.db  # Windows

# 重新启动应用
python app.py
```

#### 4. 静态文件加载失败
确保 `static` 和 `templates` 文件夹在项目根目录下，并检查文件权限。

#### 5. Python版本兼容性
如果遇到兼容性问题，建议使用Python 3.9-3.11版本。

### 日志查看
应用运行时的日志会直接显示在终端中，如遇问题可查看详细错误信息。

## 🤝 开发指南

### 项目结构
```
DEMO1/
├── app.py                 # Flask应用入口
├── requirements.txt       # Python依赖
├── app.db                # SQLite数据库文件
├── backend/              # 后端代码
│   ├── models.py         # 数据模型
│   ├── routes.py         # API路由
│   └── extensions.py     # Flask扩展
```
