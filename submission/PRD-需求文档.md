# 📄 产品需求文档（PRD）—— AI Agent 驱动的动态攻防推演靶场平台

> **版本**：v1.0 | **日期**：2026-08-11 | **作者**：闽江学院团队
> **用途**：产品视角交付物（对应网络安全靶场产品实习岗能力要求）
> **赛题**：第十九届"挑战杯"2025 揭榜挂帅（SH24，安恒发榜）

---

## 一、背景与痛点

| 痛点 | 现状 | 影响 |
|------|------|------|
| 场景静态化 | 传统靶场场景固定，演练几次后失去新鲜度 | 学员无法适应动态威胁 |
| 攻击路径单一 | 攻击方式千篇一律，缺少真实 APT 复杂度 | 训练效果打折 |
| 评估主观化 | 演练结果靠人工打分 | 不公平、不可量化 |
| 人工成本高 | 攻防对抗需要大量人力模拟对手 | 无法大规模常态化演练 |

**目标**：用 AI Agent 替代人工攻防对手，动态生成场景、自主规划攻击/防御、自动化量化评估，实现"低成本、高拟真、可量化"的常态化攻防演练。

## 二、目标用户与使用场景

| 用户 | 场景 | 核心诉求 |
|------|------|---------|
| 高校网络空间安全专业学生 | 实训课、CTF 训练、课程设计 | 拟真攻防环境、即时反馈、技能画像 |
| 高校教师/实训中心 | 教学实训、学期考核 | 批量开班、自动评分、学情统计 |
| 政企安全部门 | 红蓝对抗演练、应急演练 | 高拟真攻击模拟、防御响应验证、复盘报告 |
| 公安/竞赛组织 | 比武、选拔 | 公平量化评估、防作弊 |

## 三、功能需求

### 功能 1：动态场景生成

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F1.1 | 场景自动构建 | P0 | 基于业务模型（企业/政务/教育）自动生成网络拓扑 |
| F1.2 | 漏洞植入 | P0 | 按难度在主机上植入已知漏洞（CVE 库 12 条） |
| F1.3 | 环境参数动态调整 | P1 | 目标数量、漏洞密度、防御强度可调（C3 已实现） |
| F1.4 | 场景可视化 | P1 | 拓扑图展示主机节点与漏洞分布（C1 已实现） |

### 功能 2：智能攻击模拟

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F2.1 | 多样化攻击技术库 | P0 | 12 种攻击技术（SQLi/XSS/爆破/WebShell 等） |
| F2.2 | 攻击路径自主规划 | P0 | AI 攻击 Agent 基于漏洞库规划多步攻击链 |
| F2.3 | 攻击行为实时调整 | P1 | 防御生效后 Agent 换策略 |
| F2.4 | 攻击过程可视化 | P1 | 攻防对抗大屏实时展示决策流 |

### 功能 3：自适应防御决策

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F3.1 | 分级响应策略 | P0 | 按威胁等级（低/中/高/严重）映射响应动作 |
| F3.2 | 防御策略库 | P0 | 12 种防御策略（WAF/IDS/隔离/补丁等） |
| F3.3 | 攻防回合制对抗 | P0 | AI 攻击 vs AI 防御多轮对抗（最多 5 轮） |
| F3.4 | 响应过程审计 | P1 | 每轮决策记录可回放 |

### 功能 4：演练评估自动化

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F4.1 | 多维度指标 | P0 | 攻击成功率、防御响应时效、威胁分布（C2 已实现） |
| F4.2 | 量化评估报告 | P1 | 对抗结束后生成结构化评估（C2 已实现） |
| F4.3 | 技能画像 | P2 | 个人/团队能力画像（后续迭代） |
| F4.4 | 报告导出 | P2 | 评估结果导出为文档（后续迭代） |

## 四、非功能需求

| 类别 | 需求 |
|------|------|
| 安全 | 全 API 鉴权（token）、角色权限隔离、CORS 白名单、无默认弱口令（已修复 11 项安全漏洞） |
| 性能 | 对抗单轮 <10s（LLM 调用）；页面响应 <500ms |
| 可用性 | 一键启动（`python app.py`）；依赖清单完整 |
| 可扩展 | Agent 模块化（新增攻击/防御类型无需改核心） |
| 兼容 | Chrome/Edge/Firefox；1080p 大屏展示 |

## 五、验收标准

1. 攻击 Agent 能基于漏洞库规划 ≥3 步攻击链（LLM 或规则）
2. 防御 Agent 能按威胁等级给出分级响应（≥3 个动作）
3. 攻防对抗 ≥5 轮，前端实时展示决策流
4. 动态场景生成返回拓扑结构（主机/服务/漏洞）
5. 演练评估返回量化指标（攻击成功率/响应时效）
6. 全 API 需 token 鉴权，未登录 401
